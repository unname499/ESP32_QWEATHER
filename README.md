# ESP32_QWEATHER

### 项目描述

Arduino开发平台使用ESP32获取和风天气的第三方库。

此库用于ESP32物联网开发板通过HTTPS协议获取和风天气API所提供的免费天气信息。使用此库可以省去繁杂
的HTTPS请求以及JSON解析部分，使用几行代码即可获取有效信息，大大简化了开发步骤。

灵感来源于：https://github.com/ye-zhang0720/ESP32_HEWEATHER

由于此仓库早已过时，遂决定尽量保存调用代码，底层大部分重构。

**注意：我本人仅仅是初学者，由于觉得 JWT 生成 + HTTPS 请求 + JSON 解析太过于麻烦了，所以尽自己所能写出的此仓库。**

**如果说俗话：那就是代码写的一坨屎，别指望性能有多好**

**如有大佬发现此仓库，欢迎重构！**


### 安装（Arduino IDE）
1) 下载压缩包或克隆；

2) 解压并复制到项目文件夹下的libraries目录下；

3) 重启Arduino IDE。

### 安装（PlatformIO）
1) 在platformio.ini 文件里的`lib_deps` 填入此仓库
2) 等待安装即可
